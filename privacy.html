Privacy policy

Last updated: 18 November 2026

This policy covers Every Dex Entry Publisher, the tool the Every Dex Entry channel uses to publish its own videos, and this website.

Who uses the tool

Only the owner of the Every Dex Entry channel signs in to the tool. It is not available to the public, so it does not collect data from viewers, subscribers or anyone else.

What the tool accesses

With the owner's permission, granted through Google sign-in, the tool uses YouTube API Services to:

  • upload the channel's own videos, with their titles, descriptions and tags;
  • read the channel's basic details and the status of its uploaded videos;
  • read the channel's YouTube Analytics reports, such as views and watch time per video.

It does not read comments, messages, subscriber identities or any other person's data.

How the information is used

The information is used only to publish the channel's videos, to confirm that each upload succeeded, and to track how each video performs so later videos can be improved. It is not used for advertising, is not sold, and is not used to train AI models.

Storage and sharing

The sign-in token and the video statistics are stored in the channel owner's private systems and are not shared with or transferred to anyone else. Nothing is disclosed to third parties unless the law requires it.

Removing access

The owner can remove the tool's access at any time on the Google security settings page, security.google.com/settings/security/permissions. Once access is removed the stored sign-in token stops working, and stored statistics are deleted on request to the address below.

Google and YouTube

The tool uses YouTube API Services. Use of the tool is therefore also subject to the YouTube Terms of Service and the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Facebook, Instagram and TikTok

The same tool publishes the channel's videos to its own Facebook Page and Instagram account through Meta's APIs, and reads the statistics of those posts. With the owner's permission it also reads the channel's own TikTok profile statistics and the public statistics of its TikTok videos through TikTok's APIs. In every case it accesses only the channel's own accounts, uses the information only as described above, and shares it with no one. Access can be removed at any time in each platform's own app settings.

This website

This website sets no cookies and runs no analytics or tracking scripts. It is hosted on GitHub Pages, which may log visitors' IP addresses for security purposes under GitHub's privacy statement.
